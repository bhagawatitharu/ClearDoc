CLEARDOC INSTALLABLE APP UPDATE

This update makes ClearDoc installable as a web app on Windows and prepares it
for phone installation. It also moves document reading and saving into the
browser, so the backend is no longer needed for normal use.

WHAT IS SAVED

- Extracted text, file details, and document highlights are saved in this
  browser on this device using its local browser database.
- Documents are not uploaded and are not synced between your computer and phone.
- The selected PDF or TXT file itself is not kept after it is read.
- The older desktop library under backend\data\documents is left untouched as
  a backup. Removing a document in the updated app removes its browser copy;
  it does not erase that older backup copy.
- Scanned PDFs without an embedded text layer still need OCR; this update does
  not add OCR.

APPLY THE UPDATE

1. Extract ClearDoc-installable-upgrade.zip into:
   C:\Users\Ripple\Documents\ClearDoc
   Keep the archive's frontend folder structure and choose Replace files if
   Windows asks. This update only contains the changed and new frontend files.

2. Open a PowerShell terminal in the frontend folder:
   cd C:\Users\Ripple\Documents\ClearDoc\frontend

3. Install the added PDF reader package. This needs internet access once:
   npm install

BRING OVER YOUR CURRENT SAVED DOCUMENTS

If the older ClearDoc library contains documents you want to keep visible:

1. In a second PowerShell terminal, start the old backend:
   cd C:\Users\Ripple\Documents\ClearDoc\backend
   npm run dev

2. In the frontend terminal, start ClearDoc:
   npm run dev

3. Open http://localhost:5173 in your browser. The first time, ClearDoc copies
   the saved records from the running backend into this browser. Look for a
   message such as “Copied 1 saved document into this browser.” The old data
   folder remains as a backup.

INSTALL ON WINDOWS

1. In the frontend terminal, stop the development server with Ctrl+C.
2. Build the app and serve the installable version on the same address:
   npm run build
   npm run preview -- --port 5173 --strictPort
3. Keep that terminal open while first opening and installing the app. Go to
   http://localhost:5173 in Microsoft Edge.
4. Click Install app in ClearDoc or use Edge’s Install app option. The installed
   app can keep opening from its saved offline copy after it has loaded once.
5. The old backend terminal can be stopped after the one-time copy is complete.

Keep the preview port at 5173. The browser treats a different port as a
separate local library, so changing it would make the migrated documents
appear to be missing.

INSTALL ON A PHONE

The same app can be installed on Android or iPhone/iPad, but a phone cannot use
the computer's localhost address. The built frontend must first be placed on a
secure HTTPS web address. Only the app files are hosted; document text remains
in the phone's own browser storage. Then open that HTTPS address on the phone:

- iPhone/iPad: in Safari tap Share, then Add to Home Screen.
- Android: in the browser menu choose Install app or Add to Home screen.

The phone starts with its own empty library. Documents saved on the computer
do not automatically appear on the phone. ClearDoc is installed from the
browser as a web app; this update does not create a Windows .exe or store
download.
